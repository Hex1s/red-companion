# Чеклист ручной проверки

Запуск: `npm run tauri dev`. Всё ниже до сих пор проверялось только тестами и скриншотами на моке IPC; в живом приложении это не запускалось. Находки записывай в `docs/not-like.txt` (или рядом) в формате «где — что не так — как ожидалось».

Отмечай `[x]`, что работает. Если пункт сломан, дописывай рядом, что именно.

## 0. Запуск и данные

- [x] Приложение открывается, окно не пустое, нет красных ошибок в консоли (F12 в окне, если включено).
- [x] Закрыть и открыть заново: персонажи, укрытия, инициатива и последний удар на месте (база SQLite в папке данных приложения).
- [x] Переключение языка RU / EN: все подписи меняются, нет «сырых» ключей вида `card.damage`.
- [x] Вкладки «Персонажи» и «Справочники» переключаются (во «Справочниках» пока заглушка).

## 1. Персонажи и лист

- [x] «Новый игрок» и «Новый NPC» создают лист и выбирают его.
- [x] Правка любого поля (имя, стат, ОС) сохраняется сама примерно через секунду: статус «Сохранение…», потом «Сохранено». Кнопки «Сохранить» нет.
- [x] Сменить ТЕЛ или ВОЛЮ: «Макс. ПЗ», «Тяжёлое ранение ниже», «Спасбросок», «Макс. ЧЕЛ» пересчитываются сразу, без сохранения. Карточка справа обновляется после автосохранения.
- [x] Стат выше 10 (например ТЕЛ 14) не даёт ошибки; стат 100 или 0 (кроме УДЧ и ЭМП) — ошибка.
- [x] Ввести неверное значение, подождать: сохранения нет, ошибка видна; исправить — сохранилось.
- [x] Набираешь текст в поле, и в это время что-то меняет персонажа (например, нанесён урон из колонки): набранное не пропадает.
- [x] «Удалить» просит подтверждение; после удаления карточка исчезает из колонки и из очереди инициативы.
- [x] Навыки: группы свёрнуты; клик раскрывает; в заголовке число изученных.
- [x] Поиск навыка («пист», «язык», «родн»): остаются совпавшие навыки, группы раскрыты; пустой поиск возвращает прежний вид.
- [x] «Только изученные» оставляет навыки с уровнем больше 0.
- [x] Навыки со специализацией (Язык, Знание местности, Наука, Боевые искусства, Игра на инструменте): добавить строку («Японский»), задать уровень, убрать крестиком; сохраняется и после перезапуска.
- [x] Уровень навыка выше 10 даёт ошибку.
- [x] Критические повреждения в листе показываются с иконками.

## 2. Импорт и экспорт

Папка экспорта: `exports` внутри папки данных приложения (создаётся при запуске); «Открыть папку» открывает её в проводнике.

- [ ] «Экспорт выбранного» сразу пишет файл и показывает тост в правом нижнем углу: полный путь и кнопка «Открыть папку» (тост висит около 9 с).
- [ ] «Открыть папку» открывает проводник именно на этой папке; файл `Имя.redcompanion.json` там лежит.
- [ ] Повторный экспорт того же персонажа не затирает файл: появляется `Имя (2).redcompanion.json`.
- [ ] «Экспорт всех» делает `characters.redcompanion.json`.
- [ ] «Импорт из файла» при пустой папке не открывает окно, а показывает тост «сохраните хотя бы одного персонажа» (с кнопкой «Открыть папку»).
- [ ] При непустой папке открывается окно со списком файлов (новые сверху, с датой); клик по файлу импортирует как новых персонажей (имена не объединяются) и закрывает окно, тост «Импортировано персонажей: N».
- [ ] Файл, положенный в папку руками, виден в списке при следующем открытии.
- [ ] Испорченный файл (правь JSON) отклоняется целиком; ошибка видна в окне импорта, окно не закрывается.
- [ ] Спецификации навыков (`language:native`) переживают экспорт и импорт.

## 3. Готовые NPC

- [x] «Из шаблона»: 10 шаблонов в группах Шестёрка / Лейтенант / Мини-босс / Босс; у каждого показаны ОС головы и тела.
- [x] Клон одного: появляется в колонке, лист открыт, в заметках оружие, снаряжение и особые пометки.
- [x] Клон нескольких (например 3 Бустера): имена «Бустер 1/2/3» (или продолжают нумерацию, если такие уже есть).
- [x] ПЗ и ОС клонов независимы: урон одному не трогает другого.
- [x] Сверка с книгой (на выбор): у Телохранителя ПЗ 35 и ОС 7/7; у Киберпсихопата ПЗ 55, ТЕЛ 10, ЭМП 0; уровни навыков в листе = напечатанная сумма минус связанный стат.
- [x] Офицер СБ: в заметках есть текст про значения в скобках.

## 4. Колонка сессии и инициатива

- [x] Каждый персонаж (игроки и NPC) — карточка в колонке; новые появляются сразу.
- [x] Поле инициативы: впиши число, Enter или потеря фокуса — карточка встаёт на место в очереди (выше число — выше). Неверный текст возвращается к прежнему значению.
- [x] Кнопка с кубиком бросает РЕА + d10 (с «взрывом» на 10 и 1); тултип объясняет формулу.
- [x] Стрелки ↑ / ↓ двигают персонажа при равной инициативе.
- [x] «Старт» (треугольник в шапке): у кого инициативы не было, она бросилась сама; активная карточка в красной рамке; виден раунд.
- [x] «Следующий ход» передаёт ход, на последнем круг начинается снова, раунд растёт.
- [x] Мёртвый персонаж пропускается.
- [x] «Конец боя» сбрасывает очередь и раунд.
- [x] Все тултипы на кнопках читаются и по делу.
- [ ] Клик в любое место карточки (имя, пустое место, полоса ПЗ) выбирает её и открывает лист; клик по кнопкам и полям — нет.
- [ ] Шапка колонки (старт, следующий ход) остаётся на месте при прокрутке длинной колонки.

## 5. Урон

- [x] «Урон» на карточке открывает окно; курсор сразу в поле урона; Enter применяет.
- [x] Ввести число — Применить: ПЗ упали, ОС брони на 1 меньше, если урон прошёл; в шапке колонки строка «−N ПЗ, ОС a→b».
- [x] Кнопка с кубиком (5d6) бросает случайно, показывает грани и итог в поле урона; стрелка рядом позволяет сменить кубики и ввести грани с физических.
- [x] Две шестёрки на кубиках сами ставят «Крит» и открывают выбор травмы.
- [x] Число без кубиков: «Крит» ставится вручную.
- [x] Голова вместо тела: ОС берётся с головы. Тело по умолчанию.
- [x] «Прицельный» у головы: прошедший урон ×2. «Рука» и «Нога» у тела: предмет выпадает / нога ломается.
- [x] «½ брони» и «Без брони» меняют результат (сверь с правилом на стр. 175 и 186).
- [x] «Взрыв» работает вместе с укрытием (разрушенное укрытие не защищает).
- [x] Выбор травмы иконкой: тултип показывает название и эффект, выбранная подсвечена; «2d6» бросает случайную; без выбора травма бросается сама при применении.
- [x] Иконки травм узнаваемы? Какие стоит перерисовать — запиши.
- [x] Травма появляется в листе персонажа.
- [x] Удар по смертельно раненому: штраф спасброска растёт.
- [x] «Отменить» (стрелка в строке последнего удара) возвращает ПЗ, ОС, укрытие и травмы.
- [x] Лишних полей и объяснений в окне нет; всё нужное достижимо за 2–4 клика.

## 6. Укрытия

- [x] Иконка-щит на карточке открывает окно выбора.
- [x] Выбрать пресет («Бетон, толстое — 25»): персонаж стоит за укрытием, карточка в синей рамке, рядом с щитом ПЗ укрытия.
- [x] Второго персонажа поставить за тем же укрытием через «Уже на сцене».
- [x] Корпус и живой щит спрашивают ПЗ.
- [x] «Своё укрытие» (название и ПЗ): создаётся и доступно остальным персонажам.
- [x] Удар по персонажу за укрытием: ПЗ укрытия падают, лишний урон рассеивается, цели урон не достаётся.
- [x] Укрытие разрушено (0 ПЗ): рамка исчезает, цель получает урон; ПЗ укрытия можно поправить в окне.
- [x] «Выйти из укрытия» и возвращение: ПЗ укрытия помнятся.

## 7. Смерть, спасбросок, стабилизация, «вернуть»

- [ ] Игрок на 0 ПЗ: состояние «Смертельное», на карточке кнопка «Стабилизировать». У игрока с ПЗ больше 0 (лёгкое или тяжёлое ранение) этой кнопки нет.
- [ ] В начале хода смертельно раненого игрока на карточке спасброск (поле для грани d10); результат остаётся до конца хода. Провал (10 или больше ТЕЛ) — «мёртв»; успех поднимает штраф.
- [ ] NPC, у которого урон довёл ПЗ до 0, сразу «Мёртв»: нет смертельного ранения, спасброска, кнопки «Стабилизировать». То же при ручной правке ПЗ NPC в листе на 0.
- [ ] «Отменить» последний удар, убивший NPC, оживляет его с прежними ПЗ.
- [ ] «Стабилизировать»: окно с именем, СЛ 15, помощником (по умолчанию не сам раненый) и двумя навыками с бонусом.
- [ ] «Бросить» бросает случайно; успех закрывает окно, ПЗ становится 1, кнопка «Стабилизировать» на карточке пропадает; провал оставляет окно и пишет «итог / СЛ — не вышло».
- [ ] Поле «d10» (Enter): число от −9 до 20 принимается как готовый итог кубика, про 10 и 1 ничего не просит; вне диапазона красный «!».
- [ ] Кнопка «Стабилизировать» в окне — без броска, те же последствия, что у успеха.
- [ ] У мёртвого игрока и мёртвого NPC на карточке кнопка «Вернуть» (кнопки «Урон» нет): после нажатия 1 ПЗ, штраф спасброска 0, травм в листе нет, карточка снова живая.

## 9. Статус-зона и ошибки полей

- [ ] Правка поля в листе: в правом нижнем углу рабочей области появляется «Сохранение…» со спиннером, потом галочка «Сохранено», и сообщение плавно исчезает. Сообщения не копятся при частых правках (одно на лист).
- [ ] Статус-зона не уезжает при прокрутке листа и не закрывает важное (проверь у нижнего края).
- [ ] Ошибка сохранения (например ПЗ больше максимума) остаётся красным сообщением, пока не закроешь крестиком.
- [ ] Ввести в стат 150: красный «!» появляется в правом верхнем углу поля после паузы или когда уходишь из поля; тултип объясняет диапазон. Пока набираешь «1», «14», «140», значок не мигает.
- [ ] Верни корректное значение: значок и красная рамка пропадают, сохранение проходит.
- [ ] Такой же «!» у: имени (пустое), ПЗ, ОС, уровней навыков (больше 10), урона, граней кубиков, d10 спасброска, ПЗ укрытия, числа клонов; у каждого своё сообщение.
- [ ] Значок не обрезается краем плитки или окна (особенно у стат-плиток и полей в диалогах).
- [ ] Клик по другой карточке сразу после правки поля не теряет правку (она сохраняется при уходе с листа).
