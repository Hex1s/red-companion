# Глоссарий

Термины правил имеют **устойчивые ID** (английские, snake_case). В коде, данных и ключах локализации используются только ID; переводы живут в `src/i18n/locales/{ru,en}.json`, секция `glossary`.

Русская книга называет одно и то же по-разному (например, «Сломанная нога» в тексте и «Перелом ноги» в таблице; СЛ и DV вперемешку). Такие случаи решаются так: один ID, одно отображаемое название в локали, остальные варианты — в колонке «Синонимы книги».

| ID | ru | en | Синонимы книги |
|---|---|---|---|
| `hp` | ПЗ | HP | пункты здоровья |
| `sp` | ОС | SP | очки стойкости, стойкость брони |
| `dv` | СЛ | DV | сложность |
| `humanity` | ЧЕЛ | HUM | человечность |
| `wound.light` / `serious` / `mortal` / `dead` | Лёгкое / Тяжёлое / Смертельное ранение, Мёртв | — | |
| `armor_mode.full` / `half` / `ignored` | Полная / Половина / Игнорируется | — | |
| `area.head` / `body` | Голова / Тело | Head / Body | |

Названия критических повреждений получают ID вместе с таблицами в задаче 1.1 (`injury.<area>.<slug>`), с записью синонимов сюда.
